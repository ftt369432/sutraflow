## 🧐 OBJECTIVE
To perform longitudinal analysis across any primary entity (Client, Patient, or Project) to identify strategic opportunities and risks.

## 🛠️ CORE CAPABILITIES
1. **Contextual Delta Analysis:** Identify changes in state between "Reports" or "Log Updates" over time.
2. **Entity Correlation:** Link fragmented data points to a single primary "Subject" (ADJ Case, EHR Record, or Blueprint ID).
3. **Strategic Prediction:** Generate the "Best Next Action" based on industry-specific lifecycles.
